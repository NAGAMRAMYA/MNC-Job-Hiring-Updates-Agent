# 🤖 MNC Job Hiring & Updates Agent

An AI-powered job update agent built using **Dify, Gemini 3.5 Flash, and Resend**.

The agent analyzes MNC job hiring information and sends a formatted job update directly to email.

## 🚀 Workflow

User Input → Gemini 3.5 Flash → Resend → Email

## 🛠️ Technologies Used

- Dify
- Gemini 3.5 Flash
- Resend Email API
- HTTP Request
- AI Agent / LLM Workflow

## ✨ Features

- 🤖 AI-powered job update generation
- 🏢 MNC job hiring information processing
- 📧 Automatic email notifications
- 📝 Clear and structured job updates
- 🔐 API credentials kept private

## 📧 Email Output

The generated job update is sent directly to the configured email address.

## 🔄 How It Works

1. User provides MNC job information.
2. Dify receives the information.
3. Gemini 3.5 Flash analyzes the job details.
4. The generated update is sent through Resend.
5. The job update arrives in the user's email.

## 🔒Security

API keys and private credentials are **not included** in this repository.
